AppLayout

An input source for every app.

  1. Open Settings from the keyboard icon in the menu bar.
  2. Check one or more apps and press Add, or use Add All for every discovered app without a rule (including search-hidden apps). New rules leave the source unchanged; choose a source for each afterwards.
  3. Switch from a different app into it, then type to verify the result.

A manual source change stays until you leave and return. Apps without a rule keep the current source. Rules apply to an entire app, not individual windows, websites, or IDE projects.

In macOS Keyboard settings, turn off “Automatically switch to a document’s input source” for predictable switching. AppLayout never changes that system setting.

Launch at login is enabled on a fresh installation. Install AppLayout in Applications before the first launch. You can turn it off in Settings. Upgrades preserve the existing macOS setting. Pause stops automatic switching and persists across restarts. Quit ends the process completely.

If a saved source is unavailable, enable it in macOS or select a different one. If settings cannot be read or saved, automatic switching pauses; recovery keeps a backup of the old settings.

No typing is read. No background network requests are made. Settings stay on this Mac.

Настройка AppLayout

  1. Открой настройки через значок клавиатуры в строке меню.
  2. Отметь несколько приложений галочками и нажми «Добавить». «Добавить все» добавит все найденные приложения без правил, включая скрытые поиском. Новые правила — «Не менять»; затем назначь раскладку каждому.
  3. Перейди в приложение из другого и проверь ввод символов.

Ручной выбор сохраняется до ухода и возвращения. Без правила текущая раскладка не меняется. Правило действует для приложения целиком, без разделения на окна, сайты и проекты IDE.

Для предсказуемой работы отключи автоматическое переключение раскладки для документа в системных настройках клавиатуры. AppLayout не меняет эту настройку самостоятельно.

На новой установке автозапуск включается автоматически. Перенеси приложение в «Программы» перед первым запуском. Отключить автозапуск можно в настройках. При обновлении прежний выбор сохраняется. Пауза сохраняется между запусками; команда «Завершить» полностью останавливает приложение.

Если раскладка недоступна, включи её в macOS либо выбери другую. Ошибка чтения или сохранения настроек приостанавливает переключение; восстановление сохраняет резервную копию.

Вводимый текст не читается. Фоновых запросов в сеть нет. Настройки остаются на Mac.
