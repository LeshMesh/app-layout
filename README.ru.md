# AppLayout

**Своя раскладка для каждого приложения.** Небольшая открытая утилита для Apple Silicon и macOS 26+.

[English](README.md) · [Приватность](PRIVACY.md) · [Проверка на Mac](docs/TESTING.md)

AppLayout меняет раскладку при активации приложения. Например: Chrome → Русская, PyCharm → ABC. Вводимый текст не анализируется.

## Что уже реализовано

- Индивидуальные правила для приложений по Bundle ID.
- Переключение при клике, выборе в Dock и Cmd+Tab.
- Без правила текущая раскладка сохраняется.
- Ручная смена действует до ухода из приложения и возвращения.
- Переход между окнами одного процесса не сбрасывает ручной выбор.
- Открытие настроек AppLayout и возвращение в предыдущее приложение не сбрасывает ручной выбор.
- Выбор любого включённого и доступного для выбора источника ввода macOS, в том числе режима ввода IME.
- Поиск установленных и запущенных приложений, добавление произвольного файла .app.
- Пауза, автозапуск по умолчанию с возможностью отключения, русский и английский интерфейс.
- Локальные настройки. Нет аналитики, перехвата клавиш, чтения текста и фоновых сетевых запросов.

Правила относятся к приложению целиком. Отдельные сайты, вкладки, проекты IDE, виртуальные машины, удалённые системы и экран входа до запуска сессии не поддерживаются.

## Сборка на твоём Mac M1

Нужны macOS 26+ и Xcode 26+ с SDK macOS 26 или новее.

1. Установи Xcode и запусти его один раз, чтобы завершить настройку.
2. Выполни в Terminal:

```sh
git clone https://github.com/LeshMesh/app-layout.git
cd app-layout
bash scripts/build.sh
```

3. В Finder открой `build/local/Build/Products/Release/`.
4. Скопируй `AppLayout.app` в «Программы» и запусти.
5. Найди значок клавиатуры в строке меню.

Можно также открыть `AppLayout.xcodeproj` в Xcode, выбрать **AppLayout → My Mac** и нажать Run. Проект уже настроен для arm64 и локальной подписи.

Если Terminal использует другой Xcode, выбери нужный в **Xcode → Settings → Locations → Command Line Tools**.

## Первая настройка

1. Добавь Google Chrome, выбери нужную русскую раскладку.
2. Добавь PyCharm, выбери английскую раскладку — например ABC или U.S.
3. Остальные приложения настрой по желанию.
4. В системных настройках клавиатуры отключи «Автоматически переключаться на источник ввода документа». AppLayout сам эту настройку не меняет.
5. Переключись из другого приложения в Chrome и PyCharm и проверь ввод символов.

Если нужной раскладки нет, сначала включи её в системных настройках macOS. Она появится в AppLayout автоматически. Если приложения нет в списке, используй «Выбрать файл .app…».

Перед первым запуском перенеси приложение в постоянную папку «Программы». На новой установке автозапуск включается однократно; при необходимости macOS попросит разрешение в объектах входа. Его можно отключить в настройках — приложение не включит его повторно самостоятельно.

При обновлении с 0.1 прежнее состояние автозапуска сохраняется. Если он был выключен, включи его один раз в новом экране настроек.

Пауза сохраняется между запусками. После возобновления или пробуждения правило текущего приложения проверяется снова. Изменение правила в настройках применяется при следующем переходе из другого приложения.

## Проверки и ограничения

```sh
swift test
python3 scripts/validate.py
bash scripts/build.sh
```

GitHub Actions собирает приложение на macOS 26, запускает тесты правил и хранения, проверяет запуск приложения и создаёт шесть снимков нативного интерфейса: русский/английский, светлая/тёмная тема, пустой список и пауза. Повторить снимки на Mac можно командой `python3 scripts/render_settings.py`.

ZIP релиза — обычная сборка из успешного CI с ad-hoc подписью, без нотарификации. Исходники и инструкции самостоятельной сборки доступны выше.

Обычная сборка использует Hardened Runtime без App Sandbox. В проекте есть экспериментальная сборка с песочницей: `bash scripts/build.sh sandbox`. Её компиляция проверяется автоматически, а фактическое переключение и обнаружение приложений — вручную на Mac. Разрешения Accessibility, мониторинга ввода, записи экрана и администратора приложение не запрашивает.

IME, парольные поля, полноэкранные приложения и переходы Spaces требуют проверки на конкретном Mac. Системные ограничения ввода имеют приоритет. Приложение не пытается непрерывно удерживать раскладку или конкурировать с ручным выбором.

## Обновление и удаление

Обновления вручную через [GitHub Releases](https://github.com/LeshMesh/app-layout/releases). Заверши AppLayout, замени приложение в «Программах» и запусти снова. Правила и настройки сохранятся. Фоновых проверок обновлений нет.

Для удаления выключи автозапуск, заверши AppLayout и перенеси приложение в Корзину. Настройки хранятся в `~/Library/Application Support/AppLayout/settings.json`. Для полного удаления данных отдельно удали эту папку. Экспериментальная сборка с песочницей хранит данные в собственном контейнере macOS.
